# ブログ記事用サブエージェント

日本の専門誌向けワイン・製菓記事を書くための Claude Code サブエージェント5種。

| ファイル | 担当 | 使う段階 |
| --- | --- | --- |
| `blog-researcher.md` | リサーチ分析 | 執筆前。調査と構成案 |
| `blog-terminology.md` | 用語・表記選定 | 下書き後、推敲前 |
| `blog-editor.md` | ブラッシュアップ | 下書きの推敲 |
| `blog-opener.md` | 冒頭 | 本文確定後。タイトルとリード |
| `blog-factchecker.md` | ファクトチェック | 公開前の最終確認 |

## 設置

`README.md` を除く5つの `.md` ファイルを、次のフォルダに置く。

```
C:\Users\toshi\.claude\agents\
```

フォルダがない場合は作成する。`.claude` は隠しフォルダのため、エクスプローラーのアドレス欄に `C:\Users\toshi\.claude` と直接入力すると開ける。設置後、Claude Code を再起動する。

特定のプロジェクトでのみ使う場合は、そのプロジェクト内の `.claude/agents/` に置く。

## 使い方

Claude Code に次のように頼むと、順番に各担当へ仕事が振られる。

```
「サンテミリオン格付け2022年改定のその後」でブログ記事を書きたい。
1. blog-researcher で調査と構成案
2. 構成案をもとに下書き
3. blog-terminology で用語点検
4. blog-editor で整える
5. blog-opener でタイトルとリード
6. 最後に blog-factchecker で検証
各段階で結果を見せて、確認を待ってから次へ進んで。
```

ファクトチェックを最後に置いているのは、編集や冒頭作成の過程で数字や表現が変わるためである。

## 方針

どの担当も誇張表現を使わない設定にしてある。読まれる記事にするための工夫は、煽り文句ではなく、具体的な事実、フランス在住ならではの切り口、検索されやすい語の選択で行う。

文体を「です・ます調」にする場合は、各ファイル内の「である調」の記述を書き換える。
